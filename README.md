# 🔐 Sistema de Perfis (Admin & Usuário)

Bem-vindo ao **Sistema de Perfis**, um projeto simples em **PHP** com controle de acesso entre **administradores** e **usuários**. Ideal para quem busca uma base sólida para começar projetos com login e gerenciamento de sessão. 🚀

---

## 📌 Visão Geral

- Gerenciamento de perfis com níveis de acesso (Admin e Usuário)  
- Sessões seguras com controle de autenticação  
- Pronto para integração com banco de dados ou interface visual  
- Compatível com servidores locais (XAMPP, WAMP, Laragon)

---

## 📂 Estrutura do Projeto

```
sistema-de-perfis/
├── perfil_adm.php       → Página do administrador
├── perfil_user.php      → Página do usuário comum
├── login.php            → (Opcional) Tela de login
├── logout.php           → (Opcional) Encerramento da sessão
└── README.md            → Documentação do projeto
```

---

## ⚙️ Funcionalidades

- Acesso protegido via `session_start()` e `isset()`
- Redirecionamento automático conforme o tipo de usuário
- Estrutura limpa, comentada e pronta para evoluções futuras
